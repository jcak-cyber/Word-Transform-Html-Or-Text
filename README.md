# Word Transform Html Or Text

一个功能强大的Chrome扩展，用于将Word文档（.doc/.docx）转换为可自定义的HTML或纯文本格式。

## ✨ 功能特性

- 📄 **文档转换**: 支持将.doc和.docx文件转换为HTML或纯文本
- 🎨 **自定义模板**: 提供多种预设模板（HTML、Vue等）和自定义模板功能
- 📋 **一键复制**: 转换后的内容可直接复制到剪贴板
- 📁 **文件管理**: 支持文件上传、列表管理和删除操作
- 🎯 **拖拽上传**: 支持拖拽文件到指定区域进行上传
- 💾 **本地存储**: 使用IndexedDB进行文件本地存储
- 🎨 **现代化UI**: 基于Naive UI构建的美观界面

## 🚀 快速开始

### 安装依赖

```bash
# 使用 pnpm 安装依赖
pnpm install
```

### 开发模式

```bash
# 启动开发服务器
pnpm dev
```

### 构建扩展

```bash
# 构建生产版本
pnpm build
```

构建完成后，扩展文件将生成在 `extensions/` 目录中。

### 安装到Chrome

1. 打开Chrome浏览器，进入 `chrome://extensions/`
2. 开启"开发者模式"
3. 点击"加载已解压的扩展程序"
4. 选择项目中的 `extensions/` 目录
5. 扩展安装完成，可在工具栏看到扩展图标

## 📖 使用说明

### 基本使用

1. **上传文件**: 点击扩展图标，在弹出窗口中拖拽或选择Word文档
2. **选择转换格式**: 在设置中选择转换格式（文本或HTML）
3. **复制内容**: 在文件列表中点击"复制"按钮获取转换后的内容

### 自定义模板

1. 右键扩展图标，选择"选项"
2. 在设置页面选择模板类型：
   - **DEFAULT**: 默认模板，直接输出转换内容
   - **HTML**: HTML文档模板
   - **VUE**: Vue组件模板
   - **CUSTOM**: 自定义模板
3. 编辑模板内容，使用 `{{ template }}` 作为内容占位符
4. 点击"保存"按钮应用设置

## 🛠️ 技术栈

- **前端框架**: Vue 3 + TypeScript
- **UI组件库**: Naive UI
- **构建工具**: Vite
- **文档解析**: Mammoth.js
- **代码编辑器**: CodeFlask
- **状态管理**: Pinia
- **样式预处理**: SCSS
